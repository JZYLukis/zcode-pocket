# Security Policy

ZCode Pocket stores your ZCode account credentials and connects to the
desktop you configure. Please treat your own environment accordingly.

## Reporting a vulnerability

Do **not** open a public issue for security problems. Please use
[private vulnerability reporting](https://github.com/JZYLukis/zcode-pocket/security/advisories/new).

安全问题请使用 GitHub 私有漏洞报告渠道，勿开公开 issue。
